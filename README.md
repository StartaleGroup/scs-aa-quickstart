# Startale SCS Account Abstraction quickstart

Runnable Node.js scripts showing what you can do with [`@startale-scs/aa-sdk`](https://github.com/StartaleGroup/scs-aa-sdk) on Soneium and OP: sponsored userOps, ERC-20 gas payment, EIP-7702 delegation, Smart Sessions, account recovery, batching, plus a bundler benchmark.

Docs: <https://docs.startale.com/docs/account-abstraction>

## Setup

```bash
npm i
cp .env_template .env   # then fill in the values from the SCS dashboard
```

You only need the variables for the demos you plan to run. `npm run doctor` tells you which ones those are.

## Run a demo

```bash
npm start
```

This opens an interactive picker: choose a network, choose a demo, see the env pre-flight for exactly that script, confirm, run. Mainnet demos ask for an explicit "yes" because they spend real funds.

Non-interactive:

```bash
npm start -- startale-minato/demo_basic_userop   # run one demo by id
npm start -- demo_basic_userop                    # suffix match works when unique
npm start -- --list                               # print the catalog
npm start -- <id> --yes                           # skip the confirmation
npx ts-node src/startale-minato/demo_basic_userop.ts   # the old way still works
```

## Check your environment

```bash
npm run doctor                                   # readiness of every demo vs your .env
npm run doctor -- startale-minato/demo_7702_sdk  # one demo, with the exact missing variables
npm run doctor -- --template                     # is .env_template in sync with the scripts?
```

The doctor derives each script's requirements by scanning it for `process.env.*` reads, so it never goes stale: add a variable to a script and it shows up automatically.

## Benchmark

`npm run benchmark` compares Pimlico, Alchemy and Startale SCS bundlers on Soneium mainnet (raw RPC latency and real transactions). See [`src/soneium-mainnet/README.md`](src/soneium-mainnet/README.md) for the flags and the CI workflow.

## Maintaining

- `npm run catalog` regenerates the catalog above from `src/`; `npm run catalog:check` fails when it is stale. Both run in CI together with `npm run doctor -- --template`.
- New demo scripts go under `src/<network>/`. Put a `/** ... */` comment at the top of the file and it becomes the catalog description; otherwise one is derived from the filename.
- `src/temp/` is scratch space: its scripts are listed but flagged as WIP.
